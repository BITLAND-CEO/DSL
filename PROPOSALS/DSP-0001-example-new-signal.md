# DSP-0001 — Example New Signal

Status: DRAFT

## Problem

This proposal demonstrates how a new DSL signal can be formally proposed, discussed, reviewed, and potentially incorporated into a future version of the DSL specification.

The purpose of this example is to establish a transparent and repeatable proposal process.

## Proposal

This document proposes an example DSL signal for demonstration purposes only.

The proposed signal is:

`#DSL #EXAMPLE`

It is intended to demonstrate the structure of a DSL proposal and does not introduce this signal into the official DSL specification.

## Meaning

The proposed example signal indicates that the author is using the DSL framework to identify content as an example or demonstration.

## Examples

Example:

`#DSL #EXAMPLE`

Example with a target:

`#DSL #EXAMPLE #TARGET`

These examples are illustrative only.

## Compatibility

This proposal does not modify the current DSL specification.

No existing DSL signal or rule is changed by this proposal.

## Safety

The proposal should not be interpreted as an official DSL signal unless it is formally accepted through the defined governance process.

The proposal system must prevent individual proposals from automatically becoming part of the official specification.
