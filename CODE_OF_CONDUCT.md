# Code of Conduct

## Our Standard

The DSL project welcomes constructive participation from people with different backgrounds, skills, languages, and perspectives.

Participants are expected to:

- communicate respectfully
- criticize ideas rather than people
- provide useful technical reasoning
- avoid harassment and personal attacks
- avoid deliberate misinformation
- disclose relevant conflicts of interest

## Unacceptable Behavior

Examples include:

- harassment
- threats
- discrimination
- targeted personal attacks
- impersonation
- deliberate disruption
- malicious manipulation of project processes

## Enforcement

Project maintainers may moderate project spaces, remove abusive content, close discussions, or restrict participation when necessary to protect the project.

Major governance disputes should be documented publicly where practical.

## Scope

This code applies to project discussions, issues, pull requests, proposals, and other official project spaces.
